# Security & Privacy Policy

This public repository intentionally contains **no** secrets or private infrastructure:

- No API keys, tokens, passwords or client secrets (`.env` is git-ignored; only `.env.example` with empty values is published).
- No camera URLs, RTSP streams, IP addresses or network topology.
- No internal deployment, hosting or infrastructure configuration.
- All sensor and tower positions are **demo placements**.

If you believe something sensitive was published by mistake, please open a private
security advisory on GitHub instead of a public issue.
